# Black v1.8.0 · 提瓦特驻留终端

这一版的重点是**声音**和**角色**：内置了 29 位角色的中文语音，悄悄话会开口说话；角色增加到 56 位，并支持把你收集的立绘接进来。同时修掉了几个影响使用的小问题。

## 免安装下载

- **Windows x64 免安装版**：下载 `Black-1.8.0-Windows-x64.zip`，解压后双击 `Black.exe`。
- 不需要安装 Python；第一次运行会在同目录生成 `data/`、`journal/`、`cache/`。
- 没有代码签名，Windows 可能提示“已保护你的电脑”，点「更多信息 → 仍要运行」即可。

## 新增

- **角色语音**：内置 29 位角色、共 145 条中文语音（约 13MB）。悄悄话右下角新增喇叭按钮，亮着就播放该角色语音，点一下关闭、再点一下打开，选择会记住。
- **设置里的语音项**：显示已就绪条数、打开自定义语音目录、开关语音、开关「宽松匹配」。
- **用自己的录音**：把文件放进 `data/voice/<角色>/` 即可覆盖内置语音；支持 mp3 / wav / ogg / m4a / flac / opus。
- **56 位角色 / 180 幅内置立绘**：新增奥黛塔（冰元素，称号「翾风回雪」）。
- **补充立绘**：`data/art_extra/` 可以放自己收集的同人图，角色选择里显示为「人气 N」；设置里可一键隐藏。
- **`tools/fetch_popular_art.py`**：按真实收藏数从 pixiv 公开搜索结果里取图，自动写署名清单。
- **`tools/fetch_voices.py`**：重新抓取/更新内置语音。

## 修复

- **双击没反应**：启动入口文件缺失时会自动回退到 `app.py`，并在真的启动失败时弹窗说明原因（此前是静默失败）。
- **设置图标**：从“太阳”改成齿轮，不再和白天模式混淆。
- **缩放的闪动**：拖动窗口边缘时把界面冻结成一帧快照随窗口拉伸，重绘从 ~20ms 降到 ~3ms；最大化等一次性缩放不受影响。
- **歌单批量勾选**：再点一次可以取消勾选。
- **歌单下拉框**：一次能看到约 5 个歌单（此前只显示 1 个）。
- **合集导入勾选框**：点方框或点整行都能切换。
- **B 站下载**：某一首失败会跳过并继续，结束后列出跳过的曲目，不再中断整批。
- **添加歌曲搜索**：搜索框高度自适应，不再裁字；搜到之后再「全选」只勾选当前结果。
- **悄悄话文字**：两行台词不再被切掉半行。

## 其他

- **并行计时**：不同修习方向可以同时计时，各自累计、单独暂停。
- **托盘迷你播放器**：曲名 + 上一首/播放暂停/下一首 + 三种播放模式。
- **音效音量**：设置里 0–100 可调，0% 静音。
- **随机悄悄话角色**：每次弹出随机换一位。
