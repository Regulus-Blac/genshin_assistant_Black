# 自定义 UI 音效

把 WAV 放进这个文件夹即可替换内置音效，不需要改代码。程序优先读这里，
找不到才用上一级 `assets/audio/` 里的内置音效。

## 文件名

| 文件 | 什么时候响 |
| --- | --- |
| `click.wav` | 切换页面（修习 / 手札 / 乐音 / 交谈） |
| `interact.wav` | 摸摸头、悄悄话点「好耶」、切换立绘 |
| `confirm.wav` | 设置保存成功 |
| `open.wav` | 打开设置、角色选择、导入音乐等弹窗 |
| `cancel.wav` | 取消或关闭这些弹窗 |
| `chime.wav` | 一段计时结束的提示音 |
| `levelup.wav` | 升级 |
| `error.wav` | 音乐播放失败等错误 |

## 格式建议

- WAV，48 kHz / 16-bit / 立体声，峰值不要超过 0 dBFS
- 时长：`click`、`interact` 控制在 0.6 秒内，`chime`、`levelup` 可以在 3 秒内
- 文件名必须完全是上表中的名字（区分大小写不敏感，扩展名必须是 `.wav`）
